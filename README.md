# carlowenbelen.github.io

My personal portfolio as an AI Engineer: **https://carlowenbelen.github.io**

It's a hand-written static site in plain HTML, CSS and JavaScript, with no framework and no build step, hosted free on GitHub Pages.

- `index.html` holds the whole page: hero, work, how I build, about, stack and contact.
- `style.css` has the dark theme, the responsive layout and a reduced-motion fallback.
- `script.js` runs the terminal typing demo, scroll reveal, the mobile menu and the copy-email button.
- `design/` holds the HTML sources for `assets/og.png` (the link preview image) and `assets/apple-touch-icon.png`.

To preview it locally, open `index.html` in a browser.
