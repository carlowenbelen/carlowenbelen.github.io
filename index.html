Flagship · AI media pipeline

AI Video Editing Pipeline

One command turns raw footage into a finished YouTube video or Short. Whisper transcribes on the GPU. A rough-cut engine removes fillers, stutters and retakes, then the pipeline adds motion graphics, captions, sound effects and music ducking, and masters the audio to -14 LUFS. It can also reframe the video to 9:16 around the speaker's face.

Claude plans the edit and the laptop does the rendering, so each video costs very few AI credits.

How I build

Claude Code, set up like a small team

My rule: Claude plans, the machine does the heavy work. That keeps my tools fast, private and cheap to run.

  1. 01

    Custom skills

    Reusable skills for jobs I repeat. For example, an /edit-video skill runs the whole editing pipeline with very few credits.

  2. 02

    MCP tools & connectors

    Claude works with real tools: market data, live charts, the browser, Google Drive and Canva.

  3. 03

    Project memory

    CLAUDE.md files and a memory store, so every session starts with the full context.

  4. 04

    Local heavy lifting

    Whisper on the GPU, FFmpeg with NVENC and local AI models all run offline.

  5. 05

    Automatic checks

    Before anything counts as done, scripts check length, loudness, audio sync and page counts, and render previews.
